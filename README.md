# 🛰️ Starlink Academy

Plataforma educativa enfocada en cursos de instalación, configuración y monetización de tecnología Starlink. Dirigida a técnicos, emprendedores y empresas en Colombia que buscan dominar el internet satelital de nueva generación.

## Tech Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Framer Motion
- Lucide React
